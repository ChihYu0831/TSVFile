# TSVFile

## 一、專案簡介

本專案是一個資料檔讀取程式，主要功能是讀取單字資料檔，並將資料顯示在表格介面中。程式可以讀取 `.tsv` 或 `.txt` 檔案，將檔案中的單字、音標、音檔路徑與解釋載入到視窗中，方便使用者瀏覽與查詢單字資料。此外，本程式也提供搜尋功能，使用者可以在右上角搜尋框中輸入關鍵字，程式會即時篩選符合條件的單字或解釋，讓查找資料更加方便。

---

## 二、專案功能

本程式包含以下功能：

1. 讀取 TSV / TXT 單字資料檔
2. 將單字資料顯示於 ListView 表格中
3. 顯示欄位包含：
   - 單字
   - 音標
   - 音檔路徑
   - 解釋
4. 支援關鍵字搜尋
5. 搜尋範圍包含：
   - 單字
   - 解釋
6. 表格資料以交替顏色顯示，提升閱讀性
7. 自動調整欄位寬度
8. 狀態列顯示成功載入的單字數量
9. 離開程式前會跳出確認視窗
