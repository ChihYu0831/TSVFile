# TSVFile

## 一、專案簡介

本專案是一個資料檔讀取程式，主要功能是讀取單字資料檔，並將資料顯示在表格介面中。程式可以讀取 `.tsv` 或 `.txt` 檔案，將檔案中的單字、音標、音檔路徑與解釋載入到視窗中，方便使用者瀏覽與查詢單字資料。此外，本程式也提供搜尋功能，使用者可以在右上角搜尋框中輸入關鍵字，程式會即時篩選符合條件的單字或解釋，讓查找資料更加方便。

---

## 二、專案功能

本程式包含以下功能：

1. 讀取 TSV / TXT 單字資料檔
2. 將單字資料顯示於視窗
3. 顯示欄位包含：
   - 單字
   - 音標
   - 音檔路徑
   - 解釋
4. 支援關鍵字搜尋
5. 搜尋範圍包含：
   - 單字
   - 解釋
6. 表格資料以交替顏色顯示，提升閱讀性
7. 自動調整欄位寬度
8. 狀態列顯示成功載入的單字數量
9. 離開程式前會跳出確認視窗

---

## 三、執行說明

### 1. 開啟 TSV / TXT 檔案

程式啟動後，請依照以下步驟載入資料：

1. 點選選單中的 `開啟`
2. 選擇要讀取的 `.tsv` 或 `.txt` 檔案
3. 按下 `開啟`
4. 程式會自動讀取檔案內容，並將資料顯示在 ListView 表格中

程式支援的檔案格式包含：

- `.tsv`
- `.txt`
- 所有檔案格式

### 2. 搜尋單字或解釋

程式右上方提供搜尋功能。

使用方式：

在搜尋欄位輸入關鍵字
程式會即時篩選資料
可搜尋「單字」或「解釋」欄位
搜尋不區分大小寫

例如輸入：

abacus

即可找到單字中包含 abacus 的資料。

也可以輸入中文解釋，例如：

計算工具

即可找到解釋中包含「計算工具」的資料。

### 3. 離開程式

若要關閉程式，可以點選選單中的離開或直接關閉視窗

關閉前系統會跳出確認訊息：確定要離開嗎?

選擇 Yes 後程式會結束，選擇 No 則會取消關閉。
